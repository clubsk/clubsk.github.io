## level 3
一样先输入原payload，然后看源码

```
<form action=level3.php method=GET>
<input name=keyword  value='&quot;&gt;&lt;script&gt;alert(1)&lt;/script&gt;'>	
<input type=submit name=submit value=搜索 />
</form>
```

发现：这里的  '  是原始单引号， >  和  <  被编码成了&gt和&lt ， "  被编码成了 &quot

换成单引号看看，还是不行

原因：后端把  <  和  >  做了HTML 实体编码，把它们变成了  &lt 和  &gt 。浏览器看到的是  &ltscript&gt ，这只是一段普通的文字，不会被解析成可执行的脚本

既然不能创建新的  <script>  标签（因为  <  被禁用了），我们就只能在 现有的标签（也就是这个  <input> ）上做文章。

HTML 标签有很多 事件属性（比如鼠标点击、悬停、按下等）。这些属性不需要尖括号就能生效。

`' onclick='alert(1)`

## 超链接
超链接的本质： href  属性

在 HTML 中， <a>  标签的核心在于  href  属性（Hypertext REFerence，超文本引用）。它告诉浏览器：点击这里；去哪里？
在xss里面可以利用js伪协议执行代码

## javascript伪协议
 javascript:  是一种伪协议，告诉浏览器：冒号后面不是网址，而是一段要在当前页面上下文里执行的 JavaScript 代码

| 位置 | 示例 | 说明 |
|---|---|---|
| `<a>` 的 `href` | `<a href="javascript:alert(1)">` | 点击时执行 |
| `<iframe>` 的 `src` | `<iframe src="javascript:alert(1)">` | 加载时可能直接执行 |
| `<form>` 的 `action` | `<form action="javascript:alert(1)">` | 提交时执行 |
| `<button>` 的 `formaction` | `<button formaction="javascript:alert(1)">` | 提交表单时执行 |
| `window.location` | `window.location='javascript:alert(1)'` | 赋值后执行 |
| 地址栏 | 手动输入 `javascript:alert(1)` | 浏览器会尝试执行 |
