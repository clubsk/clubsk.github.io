# 周一
## 上课复盘
1. 所有语句必须用;结尾
2. printf("")是输出字符串，用到数学函数时需要使用#include <math>
3. 所有变量必须先定义，例如：int a=1(整型),float b=2.2(浮点型),char c='C'(字符型)
4. 基本框架
   #include <stdio.h>
   int main()
   {
   return 0;
   }
## 关于vscode的配置环境变量时和使用vscode时出现的问题
首先安装一个vscode，安装C/C++插件，但使用时提示未检测到编译器路径（系统环境变量中缺少编译器路径），于是在浏览器里跟着教程下载mingw64,复制路径；通过搜索框直接搜索环境变量，发现无法编辑（由于权限不足）
，于是从设置里面的高级系统设置（管理员权限）中打开，并选中path，把粘贴好的路径复制进去。配置好后，在vscode里面安装code runner插件，使运行更加便捷。解决方案2：卸载vscode，下载老师发的code blocks，可以直接使用
