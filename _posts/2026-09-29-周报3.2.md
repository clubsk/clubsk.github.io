## 端口范围简单理解

- 0~1023：知名端口，通常分配给系统服务
- 1024~49151：注册端口，常见应用服务会用到
- 49152~65535：动态/临时端口，客户端通信时临时使用

## 一些常见端口
| 端口 | 服务 | 用途 |
|------|------|------|
| 20/21 | FTP | 文件上传、下载 |
| 22 | SSH | Linux 远程登录、安全运维 |
| 23 | Telnet | 远程登录，明文，不安全 |
| 25 | SMTP | 发送邮件，很多云环境默认受限 |
| 53 | DNS | 域名解析 |
| 80 | HTTP | 网页访问 |
| 110 | POP3 | 接收邮件 |
| 143 | IMAP | 接收/管理邮件 |
| 443 | HTTPS | 加密网页访问 |
| 3306 | MySQL | 数据库服务 |
| 3389 | RDP | Windows 远程桌面 |
| 5432 | PostgreSQL | 数据库服务 |
| 6379 | Redis | 缓存/数据库服务 |
| 8080 | HTTP 代理/Tomcat | 替代 80 端口，常用于测试 |
| 27017 | MongoDB | NoSQL 数据库 |
