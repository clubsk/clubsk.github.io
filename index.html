欢迎来到 clubsk.github.io

由 GitHub Pages 托管的静态站点模板

关于这个站点

这是一个最小的静态站点模板，包含 index.html、styles.css 和说明文档 README.md。你可以编辑这些文件并把内容替换为你自己的页面。

部署

  1. 确保本仓库名称为 clubsk.github.io（已满足）。
  2. 文件已提交到 main 分支的根目录，GitHub Pages 会自动发布。
  3. 访问：https://clubsk.github.io

自定义域（可选）

如果你有域名，把域名写入仓库根的 CNAME 文件或在 Settings → Pages 中填写自定义域，然后在域名注册商中配置 DNS（A 记录或 CNAME）。
