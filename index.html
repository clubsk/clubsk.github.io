如何添加文章（示例）

在仓库根目录下创建 posts/ 目录，每篇文章可以作为一个单独的 HTML 或 Markdown 文件（例如 posts/2026-09-03-hello.html）。在 

{
  "posts": [
    {
      "title": "欢迎来到我的博客",
      "date": "2026-09-03",
      "excerpt": "这是第一篇文章的摘要。",
      "url": "/posts/2026-09-03-hello.html"
    },
    {
      "title": "第二篇文章",
      "date": "2026-08-20",
      "excerpt": "更多内容...",
      "url": "/posts/2026-08-20-second.html"
    }
  ]
}

部署
