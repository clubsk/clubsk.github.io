# clubsk.github.io

这是为 clubsk.github.io 提供的静态站点模板（最小可用版）。

包含文件：

- `index.html`：站点主页
- `styles.css`：基础样式
- `README.md`：说明文档（你正在查看）

如何使用：

1. 修改 `index.html` 和 `styles.css`，将内容替换为你自己的页面。
2. 将更改提交到 `main` 分支（此仓库为用户站点仓库，GitHub Pages 会从根目录发布）。
3. 访问：https://clubsk.github.io 当更改部署完成后即可查看。

自定义域：

- 在仓库根新建 `CNAME` 文件，文件内容为你的自定义域（例如 `example.com`），或在仓库设置 Pages 中填写自定义域。
- 配置域名注册商的 DNS（裸域使用 4 个 GitHub A 记录，子域使用 CNAME 指向 `clubsk.github.io`）。
